升级 / 回滚

⚠️ 回滚到 v0.0.5 前请先做完整备份（阅读器里 💾 按钮），并删除 PDF 书籍、恢复默认背景。 旧代码无法打开 v3 数据库，直接切回旧版本会报 VersionError，需要执行「删除数据库」后用备份恢复。 
回滚步骤（与 CHANGELOG 一致）：
1. 在 v0.0.6 阅读器中点 💾 做一次完整备份（包含 PDF 与背景图）。
2. 在「书库管理」删除 PDF 书籍；在「外观设置」恢复默认背景（也可用本页清理按钮）。
3. 把代码切回 v0.0.5 并重新部署。
4. 本页点「删除数据库」，确认删除 reader-db 与旧库。
5. 用 v0.0.5 打开站点，从备份恢复笔记 / 书籍（旧版本会自动忽略 pdfs/ 与 assets/ 条目）。
